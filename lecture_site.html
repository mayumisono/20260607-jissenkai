Section 1

GASとは？

15 min

GASって何？

GAS（Google Apps Script）は、Googleのサービスを自動化・連携できるプログラミング言語です。

  • Google Apps Script の略
  • Googleアカウントがあれば今日から無料で使える。サーバーも不要
  • スプレッドシート・フォーム・Gmail・カレンダーなどと自由に連携できる

GASでできること

EXAMPLE 01
✉️ メール自動送信
アンケートに回答してくれた人へ、お礼メールをスプレッドシートから一斉送信する
EXAMPLE 02 ← 今日やること
🌐 自動集計 & Webページ公開
毎月の売上データをスプレッドシートで自動計算し、URLを開くだけで見られるWebページとして公開する
EXAMPLE 03
📅 カレンダー連携
スプレッドシートに入力したイベント情報を、Googleカレンダーに自動で一括登録する

GASの「関数」って何？

GASのコードは 「関数（ファンクション）」 という部品の集まりでできています。 それぞれの関数が役割を持って動くことで、ひとつのシステムが完成します。 カレー作りに例えるとイメージしやすいです。

デプロイとは？

GASのコードを書いたら、「デプロイ」 することで、そのコードがWebアプリとして公開されます。 デプロイとは「作ったものを動く状態にして公開すること」です。

JavaScript (Code.gs) — メール自動送信 
// スプレッドシートを開いたとき、上部メニューに「📧 メール送信」を追加する
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu("📧 メール送信")
    .addItem("お礼メールを一斉送信する", "sendThankYouEmails")
    .addToUi();
}

// メール送信の本体
function sendThankYouEmails() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();

  // 「メール設定」シートから件名・本文を取得
  const config  = ss.getSheetByName("メール設定").getDataRange().getValues();
  const subject = config[0][1]; // B1: 件名
  const body    = config[1][1]; // B2: 本文

  // 「参加者リスト」シートから宛先を取得
  const rows = ss.getSheetByName("参加者リスト").getDataRange().getValues();

  for (let i = 1; i < rows.length; i++) {
    const name  = rows[i][0]; // A列: 名前
    const email = rows[i][1]; // B列: メールアドレス

    MailApp.sendEmail({
      to:      email,
      subject: subject,
      body:    name + " さん\n\n" + body
    });
  }
  SpreadsheetApp.getUi().alert("✅ 送信完了！");
}

JavaScript (Code.gs) — カレンダー自動登録 
// スプレッドシートを開いたとき、上部メニューに「📅 カレンダー登録」を追加する
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu("📅 カレンダー登録")
    .addItem("イベントをカレンダーに登録する", "addToCalendar")
    .addToUi();
}

// カレンダー登録の本体
function addToCalendar() {
  const sheet    = SpreadsheetApp.getActiveSpreadsheet()
                              .getSheetByName("イベント一覧");
  const rows     = sheet.getDataRange().getValues();
  const calendar = CalendarApp.getDefaultCalendar();

  // 1行目はヘッダーなので2行目（index 1）から処理
  for (let i = 1; i < rows.length; i++) {
    const title = rows[i][0]; // A列：イベント名
    const start = new Date(rows[i][1]); // B列：開始日時
    const end   = new Date(rows[i][2]); // C列：終了日時

    calendar.createEvent(title, start, end);
  }
  SpreadsheetApp.getUi().alert("✅ カレンダーへの登録が完了しました！");
}
  1. 1スプレッドシートのシート名を 「イベント一覧」 にして、A・B・C列にデータを入力
  2. 2コードをGASエディタに貼り付けて保存（Ctrl+S）
  3. 3スプレッドシートを開き直すと上部に 「📅 カレンダー登録」 メニューが追加される
  4. 4「イベントをカレンダーに登録する」をクリック
  5. 5Googleカレンダーを開いて、イベントが追加されていたら成功！
